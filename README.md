# GCP GitHub runners

Self-hosted GitHub Actions runners on Google Cloud.

The current canonical deployment uses Google Cloud Spot VMs. Portability means deployment into unrelated Google Cloud projects. Standard VM scheduling and other clouds are outside this initial route.

This is a private migration scaffold. Deployment code and deployment qualification are not yet included. This scaffold provisions no infrastructure.

License notice, required attribution and public security contact remain under migration review. No public release is made by this scaffold.
