# Provenance and license facts

This repository is a sanitized snapshot and portable continuation of selected GitHub runner infrastructure source. The imported source history was collapsed into a snapshot; it does not retain separate commits for each original change. Subsequent migration work supplies new portable implementations and tests. Snapshot author/committer metadata identifies the requested snapshot publisher, not an assignment of all underlying copyright.

The selected source's root, webhook and cleanup package metadata declared `MIT`. The selected source trees contained no root license text or copyright notice; package author fields were empty. No copyright holder, assignment, DCO certification or signed commit is invented here. The owner must resolve the applicable root license/notice before a public release.

Third-party dependencies and worker binaries retain their own licenses. Preserve their notices and record the exact dependency/image inventory when packaging or distributing. Historical private operational documents, credential-bearing configuration and source ancestry are intentionally not part of this distribution.
